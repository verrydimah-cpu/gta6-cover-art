**VICE COVER STUDIO** — a static, fully offline web app that turns a photo and a caption into GTA-poster-style cover art: a multi-panel ensemble collage with angled gold-framed panels, editable cast role tags, a retro-chrome headline, a neon script subtitle and a Vice City sunset grade, exported as a PNG at 1080 × 1080, 1080 × 1350 or 1920 × 1080. Seven layouts (the Ensemble Poster leads), four colour grades, three caption styles, per-panel crop / zoom / punch, a film finish with an in-app Sharp control, nine Surprise Me recipes, and eleven sample photographs — including two real garage shots — that can fill any panel alongside your own uploads. One renderer draws both the live preview and every export, so what you see is exactly what you post.

## Run it

```sh
node serve.ts   # then open http://localhost:8080
```

To build the hand-in instead: `mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts`.

The Anton typeface is vendored under `app/fonts/` under the SIL Open Font License (see `app/fonts/OFL.txt`); every photograph in `app/samples/` is AI-generated or the entrant's own.
